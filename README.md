The goal of this project is to learn to build, implement, and test functions.

## About the function

The function I created (which can be found in the Rmd file) is responsible for grouping your data by a variable of choice, and then calculating the mean and median of another numerical variable based on this grouping.

## Running the Code

The mini-data-analysis was written using RMarkdown and both the Markdown (md) and RMarkdown (Rmd) files are made available to you in this repository. To run the code, you may download the file by selecting it in the main branch and clicking "Download raw file". You may also work on the file directly by cloning the repository on RStudio (New Project -\> Version Control -\> enter repository url). This will allow you to pull the latest updates from the file and share your changes with other collaborators.
